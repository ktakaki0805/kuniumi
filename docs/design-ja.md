# kuniumi 設計書：惑星規模・リアル志向の地図生成パイプライン

> リポジトリ内の設計書の正本です。変更は該当するチケットのコミットで行います。決定事項の詳細は `docs/decisions.md`（D-01 …）、実装上の規約は `docs/conventions.md` にあります。

## 前提と設計方針

結論：地球科学のモデルを簡略化して順に通し、地形と気候を2〜3回往復させるオフライン・パイプラインにします。ゲームには最終成果（標高・水系・気候区分・バイオーム）だけを渡します。

前提は、惑星全体を対象とし、生成時間は数分〜1時間程度まで許容し、リアルさを最優先することです。

- **形を描かず、原因を作る。** 標高をノイズで描く代わりに、プレート運動 → 隆起速度 → 侵食との均衡、という順で地形を発生させます。川・尾根・海岸線の整合性はここから自然に出ます。
- **地球で検証済みのモデルの簡略版を使う。** stream power 則、アイソスタシー、海洋底の冷却モデル、エネルギー収支モデルなどです。パラメータは地球の値を初期値にします。
- **段階間にフィードバックを入れる。** 気候が侵食速度を決め、侵食後の地形が気候を変えます。完全な連成は不要で、交互に2〜3回回せば十分です。
- **解像度を2段に分ける。** 惑星全体は約30 km 間隔の格子で計算し、ゲームで使う地域だけを後段で高解像度化します。
- **地球を正解データとして使う。** 地球に近い条件を入れたとき、地球の統計（高度分布、陸地率、気候区分の面積比）に近づくよう調整します。

### 規約の要点

詳細は `docs/conventions.md` にあります。

- **単位。** 内部とファイル形式は SI 基本単位（m、s、kg、K）とラジアンのみ。人が書く設定ファイルだけ、キー名に単位を明記して km や度を使えます。
- **座標。** 惑星中心が原点の右手系で、+Z が自転軸の北、+X が経度0°の赤道です。位置は単位ベクトルが正本で、緯度経度は派生量です。
- **標高と時刻。** 固体表面は基準半径からの差（m）です。海面は同じ基準の別の値として持ちます。時刻はシミュレーション開始を 0 s とします。
- **決定論。** f32、標準ライブラリの三角関数など、HashMap・HashSet は clippy で禁止です。直接使う浮動小数点演算は、結果が一意に決まるもの（四則演算、sqrt、mul_add、丸め、剰余、絶対値、比較、整数との変換など）に限ります。数学関数は libm クレートを通し、乱数はシードとステージ名から派生させます。並列化は分割と集計の順序を固定します。

## パイプライン全体像

9段階を上から順に通し、後段ほど前段の結果に依存します。例外は気候と侵食で、この2つだけは2〜3回往復させます。

```
入力と土台      惑星パラメータ        半径・自転周期・軸傾斜・海水量・恒星光度
                    ↓
                球面格子              フィボナッチ球＋ボロノイ、約65万セル
                    ↓
固体地球        プレートテクトニクス  3〜5億年の運動学的シミュレーション
                    ↓
                地殻から標高へ        年代→水深、厚さ→標高、海水量→海面
                    ↓
地形と気候の連成  気候                月別の気温・降水・風・海流        ←┐
                    ↓                                                     │ 2〜3回往復
                侵食と地形発達        隆起と侵食の釣り合い、堆積、氷河 ─┘
                    ↓
水と生物圏      水文                  流出、湖の水収支、川と塩湖
                    ↓
                気候区分とバイオーム  ケッペン区分、植生、特殊バイオーム
                    ↓
仕上げ          高解像度化と出力      地域の再計算、ゲーム用レイヤー
```

## 球面グリッドとデータ構造

推奨：ジッタを加えたフィボナッチ球の点群に球面ボロノイ分割をかけ、約65万セル（間隔およそ30 km）を全段階の共通格子にします。

正距円筒図法の平面格子は使いません。極で格子が潰れ、風・海流・プレート運動の計算が歪むためです。正二十面体の分割格子も候補ですが、規則的すぎて川が格子方向に揃いやすくなります。不規則な格子のほうが水系は自然に見えます。

| 点数 | 平均セル間隔（地球半径） | 用途 |
| --- | --- | --- |
| 約16万 | 約60 km | 試作・パラメータ探索 |
| 約65万 | 約30 km | 本番の全球計算 |
| 約260万 | 約15 km | 余裕があれば最終の侵食段階のみ |

- **ドロネー分割の作り方。** 球面上の点群の3次元凸包がそのまま球面ドロネー分割になります。凸包の構築は自作し、向きの判定には厳密な幾何述語（robust クレート）を使います。双対がボロノイ分割で、各セルの面積・隣接辺の長さ・中心間距離もここで求めます。
- **隣接の持ち方。** 隣接リストは CSR 形式（オフセット配列＋隣接ID配列）で、外から見て反時計回りに並べます。流向計算・拡散・移流はすべてこの上で動きます。
- **データの持ち方。** セルごとの属性は、属性ごとの配列（SoA）にします。
- **2種類の格子。** 地形と気候は固定の格子で、プレートの地殻は移動する点群で持ちます。プレート段階では数ステップごとに地殻点を固定格子へ写し直します。
- **再現性。** すべての乱数はシード付きの生成器から段階ごとに分岐させます。

## プレートテクトニクス

推奨：Cortial ら（2019）型の運動学的シミュレーションを採用し、超大陸から始めて3〜5億年分を1〜2 Myr刻みで進めます。境界の応力だけで一発生成する簡易法より、時間発展させるほうがリアルさで明確に有利です。古い造山帯（低くなった山脈）、大陸棚の広い受動的縁辺、海洋底の年代勾配といった「履歴の痕跡」が自然に残るためです。実装は、まず簡易法でパイプライン全体をつなぎ（M2）、後で時間発展に置き換えます（M6）。

### 表現

- 各プレートは剛体の地殻点群で、惑星中心を通る回転軸（オイラー極）と角速度を持ちます。
- 地殻点の属性は、地殻種別（大陸/海洋）、地殻厚、形成年代、最後の造山の種類と年代、褶曲の方向、岩石の侵食されやすさです。
- 1ステップごとに点を回転させ、固定格子上で「どのプレートの点が何枚重なっているか」「どのプレートの点もない隙間」を判定します。重なりが収束境界、隙間が発散境界です。
- 約10ステップごとに全点を固定格子へ写し直し、点の偏りを解消します。

### 境界ごとの処理

| 境界 | 判定 | 処理 | 生まれる地形 |
| --- | --- | --- | --- |
| 海洋–大陸 収束 | 重なり、片側が海洋 | 重い海洋側を沈み込ませ、上盤側を前線からの距離に応じて隆起 | 海溝、アンデス型の火山弧 |
| 海洋–海洋 収束 | 重なり、両側海洋 | 古い（重い）方を沈み込ませる | 海溝、弧状列島 |
| 大陸–大陸 収束 | 沈み込む側の大陸が前線に到達 | 大陸塊を相手プレートに縫合し、広範囲を厚化・隆起。両プレートの合体も判定 | ヒマラヤ型山脈、高原 |
| 発散 | 点のない隙間 | 年代0の海洋地殻を生成。大陸内なら地溝から始める | 中央海嶺、地溝帯、新しい海 |
| すれ違い | 相対速度が境界に平行 | 標高は変えない | トランスフォーム断層 |

### プレート速度と分裂

- **速度。** 地球のプレートは年1〜10 cm（10〜100 km/Myr）で動きます。沈み込む板を多く抱えるプレートほど速いという観測があるため、「沈み込み境界の長さ」に比例した速度を与えると現実的です。大陸の多いプレートは遅くします。
- **分裂（リフト）。** 大きな大陸プレートほど、また前回の分裂から時間が経つほど確率を上げます。分裂線は古い縫合帯を優先して通すと、大陸が同じ場所で何度も開閉するウィルソン・サイクルが再現されます。
- **ホットスポット。** マントルに固定した数個の湧昇点を置き、上を通過する地殻を隆起させます。ハワイ型の、年代順に並ぶ島列ができます。

### 初期条件の目安

- 大陸地殻の面積を全球の約40%にします（地球では大陸棚を含めた大陸地殻が約4割、陸地は約3割）。
- 一発生成（M2）では、大陸の成長が大陸の内側に残す、表面積の0.1%未満の囲まれた海（多くはセル1〜数個の穴）を大陸地殻で埋め、同じ面積を最後に成長した海岸から削ります。大陸地殻の割合は変わりません。それより大きな内海は残します。
- 1つの超大陸と10〜15枚のプレートから始めます。超大陸の分裂から始めると、大西洋型（受動的）と太平洋型（活動的）の大陸縁辺が両方そろいます。
- 終了時刻の手前20〜50 Myrの隆起速度を記録し、侵食段階に渡します。

## 地殻から標高へ

結論：標高は直接いじらず、海洋は「地殻の年代」から、大陸は「地殻の厚さ」から計算します。海面は固定値にせず「海水の量」から決めます。この3つで、地球の高度分布の特徴である二山型（大陸の山と深海の山）が自然に現れます。

### 海洋底：年代から水深

海洋地殻は海嶺で生まれてから冷えて沈んでいきます。Parsons & Sclater（1977）の経験式を使います（d は水深 m、t は年代 Myr）。

```latex
d(t) = 2500 + 350\sqrt{t} \quad (t < 26.3)
```

```latex
d(t) = 6400 - 3200\, e^{-t/62.8} \quad (t \ge 26.3)
```

原論文の2式は適用範囲が20〜70 Myrで重なっており、70 Myrで切り替えると約78 mの段差が出ます。そこで2式が交わる約26.3 Myr（水深約4,294 m）で切り替えます。海嶺で約2.5 km、古い海洋底で約6 kmになり、海嶺から両側へゆるやかに深くなる地形が年代だけで決まります。

一発生成（M2）では履歴がないため、年代は次のように決めます。各海嶺セルから、それぞれの半拡大速度でプレート内に広がる前線を考え、各セルに最初に届いた前線の到達時間を求めます（隣の海嶺セルと速度が大きく違っても、年代の継ぎ目はほとんどできません）。ただし前線の速度には下限を設け、全拡大速度が1 cm/yr（半拡大速度0.5 cm/yr）より遅い海嶺セルは、その速度で広がるとみなします。2枚のプレートの相対極に近づくと拡大速度は0に近づくため、下限がないと、相対極の近くに集まった非常に遅い海嶺セルの隣で年代が1セルで100 Myr近く跳び、海嶺の横に数kmの段差ができます。地球の超低速拡大海嶺（ガッケル海嶺、南西インド洋海嶺など）は全拡大速度が約1.2 cm/yr未満の海嶺で（Dick, Lin & Schouten 2003）、最も遅いガッケル海嶺の東部でも約0.6 cm/yrです（O'Connor ほか 2021）。この時間の順位を、地球の海洋底の面積–年代分布（面積が年代とともに直線的に減る三角形の分布、最大180 Myr、平均60 Myr; Parsons 1982）に写して年代とします。発散境界をひとつも持たないプレートには届く前線がないため、その海洋底は、海嶺が失われた古い海洋底とみなします。海嶺から前線が届く海洋底をすべて並べたあとに、プレート境界からの距離の順に並べ、分布のいちばん古い部分を割り当てます（地球のパラメータでは、そうしたプレートが海洋底の1〜2割を占める世界で、境界がおよそ110〜120 Myr、内部が180 Myr近く）。海洋どうしの収束境界で古い側が沈み込む規則とも整合します。時間発展（M6）では年代は履歴から直接決まります。

### 大陸：厚さから標高（アイソスタシー）

大陸地殻はマントルに浮いており、厚いほど高くなります（エアリー型アイソスタシー）。地殻密度2,800 kg/m³、マントル密度3,300 kg/m³とすると、厚さが1 km増えるごとに標高は約0.15 km上がります。この比は密度だけで決まり、重力加速度には依存しません。

- 標準的な大陸地殻（約35 km）が標高約300 mになるよう基準を合わせます。
- 衝突で70 km程度まで厚くなると標高は約5.6 kmになり、チベット型の高原が再現されます。
- 分裂で薄くなった縁辺部は海面下に沈み、大陸棚と大陸斜面になります。一発生成（M2）では、収束前線以外の海岸（面積が表面の0.5%以上の海に面するもの）と大陸内のリフトから内陸へ、地殻が海岸線で15 km、内陸600 kmで35 kmに戻るよう直線的に薄くします。地球の水量では海面が基準より約0.7 km下になるため、海岸から約400 kmまで（厚さ約28 km以下）が沈み、陸地率は約29%になります。

### 古い山脈を低くする

プレート段階では細かい侵食は計算しません。代わりに、造山で増えた厚さを時間とともに指数関数的に減らします（時定数は1億年程度から調整）。新しい山脈は高く鋭く、古い山脈は低くなだらかという差が出ます。細部の侵食は後段で行います。

### 海面：海水量から決める

海水の総量 V をパラメータにし、次の式を満たす海面高さ z を二分探索で求めます（h は各セルの標高、a はセル面積）。

```latex
\sum_i \max(0,\, z - h_i)\, a_i = V
```

地球の海水量は約13.4億 km³ で、陸地は表面の約29%です。陸地率を直接指定するのではなく、海水量と大陸地殻量の組み合わせから結果として決まるようにします。

すべてのセルが水没する水惑星（V が、最も高い地点 h_max まで満たしたときの水量 C 以上）では、h_max より上の水 V − C を、半径 R_top = R + h_max の球に載る球殻とみなして海面を求めます（R は惑星半径、A はセル面積の合計で約 4π sr）。

```latex
z = h_{\max} + \left(R_{\mathrm{top}}^3 + \frac{3(V - C)}{A}\right)^{1/3} - R_{\mathrm{top}}
```

水を基準面の面積に一様な層として広げる近似は、半径に比べて深い海では大きく外れます。半径 1,500 km の惑星に 10¹¹ km³（惑星の体積の約7倍）の水を置くと、層の近似では海面が基準面の 3,533 km 上になりますが、球殻では 1,508 km 上になり、各セルの水柱をすべて球殻として計算した値との差は数 m（相対 10⁻⁶ 程度）です。h_max より下の水は上の式のまま、各セルの水柱を基準面での面積の柱として数えます。その誤差は水量の約 2|h|/R で、半径 1,500 km でも約1%以下です。

## 気候モデル

推奨：自前の「中間複雑度」気候モデルを月別（12か月）に回し、実在の地球の地形を入力して観測気候に合うよう較正します。リアルさを決めるのは各要素の精密さより、海流・季節風・雨陰・湧昇といった因果がそろっているかどうかです。

### 構成要素

| 要素 | 手法 | 再現される現象 |
| --- | --- | --- |
| 日射 | 緯度・月ごとの日平均日射を解析式で計算（自転軸傾斜・離心率・近日点黄経・恒星光度から） | 季節、極夜、白夜 |
| 気温 | 球面上の2次元エネルギー収支モデル。陸と海で熱容量を変え、雪氷でアルベドを上げる。最後に標高で約6.5 K/km下げる | 大陸性気候、海洋性気候、氷のフィードバック |
| 気圧帯 | 赤道低圧帯（熱赤道に季節追従）、亜熱帯高圧帯、亜寒帯低圧帯、極高圧帯を緯度帯で置き、陸と海の温度差で熱的高低気圧を重ねる。循環セルの数と幅は自転速度から決める | 季節で移動する降水帯、モンスーン |
| 地上風 | 気圧場から地衡風を求め、摩擦で低気圧側へ20〜30°傾ける。赤道付近は気圧勾配に直接沿わせる | 貿易風、偏西風 |
| 海流 | 風応力を入力に、海盆ごとに Stommel 型の流線関数を解く（陸地境界で流れ0） | 西岸強化（黒潮・湾流）、環流、周極流 |
| 海面水温 | 海流で熱を移流。沿岸湧昇（海洋の東岸、つまり大陸の西岸で強い）で冷やす | 暖流沿いの温暖な高緯度、寒流沿いの海岸砂漠と霧 |
| 水蒸気 | 風で移流。海面から蒸発（水温と風速に依存）、陸地からも蒸発散で再供給 | 内陸ほど乾燥、熱帯雨林の水循環 |
| 降水 | 飽和水蒸気量を超えた分＋収束域＋風上斜面の上昇で降らせ、風下は乾かす | 赤道多雨、亜熱帯砂漠、雨陰 |
| 氷床 | 年間の降雪が融解を上回るセルに氷を積み、標高とアルベドに反映 | 極冠、山岳氷河、氷床の厚み |

### 計算の流れ

1. 地形、海陸分布、惑星パラメータ（半径、自転周期、軸傾斜、離心率、近日点黄経、恒星光度、温室効果の強さ）を入力します。
2. 12か月を1年としてループし、各月で日射 → 気温 → 気圧と風 → 水蒸気と降水の順に更新します。海流は年平均の風で年1回だけ解けば十分です。1年（公転周期）は同じ長さの12か月に分け、北半球の春分を年初から 79.5/365 年（365日暦の3月21日正午。PMIP の慣例）に置きます。軌道上の位置はケプラー方程式で時刻から求めます。
3. 年ごとの差が十分小さくなるまで数年分回します。
4. 出力は各セルの月別気温・月別降水・風・海面水温で、ケッペン区分とバイオームの入力になります。

地形性降水は、全球段階では「風と斜面の内積に比例して降水を増やし、その分を水蒸気から引く」簡易法で十分です。高解像度化の段階では、Smith & Barstad（2004）の線形理論（地形の波長に応じて降水分布を計算するモデル）に置き換えます。

### 較正：地球を正解として使う

同じ気候モデルに地球の実地形（ETOPO 2022）を入力し、観測の気温・降水・ケッペン区分図と比べてパラメータを合わせます。これがリアルさを担保する最大の手段です。特に、亜熱帯の西岸砂漠、モンスーン域、偏西風帯の大陸西岸の多雨が再現されるかを確認します。データはスクリプトでダウンロードし、リポジトリには入れません。形式の変換は `tools/` の Python スクリプトで行います（D-11、D-16）。

実地形を取り込むまで（M4-08）は、地球のパラメータで生成した世界（シード 1）を地球の代わりにし、North & Coakley による海面気温の観測フィットに合わせて、エネルギー収支モデルの温室効果の強さ `A` と熱拡散係数 `D` を仮に較正します（M4-02）。海流が熱を運ぶモデル（M4-05）では、`D` が担っていた海洋の分を海流が運ぶので、同じ世界・同じ目標で `A` と `D` を較正し直します。

### ExoPlaSim との使い分け

ExoPlaSim（系外惑星向けの大気大循環モデル）は比較の基準として使い、コードは取り込みません。

| 観点 | 自前モデル | ExoPlaSim |
| --- | --- | --- |
| 物理の忠実さ | 規則と簡略式の組み合わせ | 3次元の大気大循環モデル |
| 解像度 | 全球格子と同じ（約30 km） | 数百 km（T21〜T42 程度） |

## 侵食と地形発達

推奨：プレート段階が出した隆起速度 U を入力に、地形発達モデル（stream power 則＋斜面拡散＋堆積）を全球格子で1,000〜3,000ステップ回します。リアルさへの寄与が最も大きい段階で、川の樹状網、尾根、谷、沖積平野、大陸棚がここで生まれます。

### 基本方程式

```latex
\frac{\partial h}{\partial t} = U - K\, Q^{m} S^{n} + K_d \nabla^2 h + G
```

- h は標高、S は流下方向の勾配、Q は上流から集まる流量です。流域面積ではなく「降水量×面積」の累積を使うことで、多雨地域ほど速く削れる気候との連成が入ります。
- 第2項が河川侵食、第3項が斜面のなだらかな崩れ（拡散）、G が堆積です。
- m = 0.4〜0.5、n = 1 から始めます。n = 1 にすると、Braun & Willett（2013）の陰解法で各ステップを O(N) で解け、時間刻みを1〜10万年と大きく取っても安定します。

### 1ステップの処理

侵食は、地殻段階の面の陸セルに最大 1 m の一様乱数（ワールドのシードから導く乱数ストリーム `erosion/roughness`）を加えた面から始めます。完全に水平な陸では、窪地処理の ε 勾配が最寄りの出口へ向かう平行な直線の流路を引き、最初の数ステップの侵食がそれを谷に刻んで、平行な川と羽状の支流が残ります。Barnes ほか（2014b）の平坦地処理（高い側から離れる勾配の重ね合わせ）も、数百セルに及ぶ平坦地では流れを平行のままにします。わずかに乱した初期面から始めると樹枝状の水系になります。Cordonnier・Bovy・Braun（2019）も FastScape の計算を「小さな乱れを加えた平坦面」から始めています。侵食のステップ数が 0 のときは加えません（チケット M3-06）。

1. **流向。** 各セルから最急降下方向の隣接セルを受け手にします。
2. **窪地の処理。** 流れが閉じた窪地に溜まらないよう、Priority-Flood（Barnes ほか 2014a）で窪地を埋めた面の上で流路を決めます。侵食は元の面に対して行います。より効率的な Cordonnier・Bovy・Braun（2019）の流域グラフ法は、必要になったら導入します。
3. **並び順と流量。** 河口から上流へ向かう並び順（スタック）を作り、逆順に降水×面積を足し合わせて Q を求めます。
4. **河川侵食。** スタック順に陰解法で標高を更新します。
5. **斜面拡散。** 拡散項を陰的に解きます。
6. **堆積。** Yuan ほか（2019）の効率的な堆積付き解法で、勾配が緩む場所に土砂を落とします。これがないと盆地が削れすぎ、扇状地や平野ができません。
7. **海への土砂。** 河口に届いた土砂を海側へ拡散させて積みます。デルタと大陸棚の縁が育ちます。
8. **アイソスタシー反発。** 削った分だけ地殻を薄くし、その約85%を隆起として戻します。山は削られても見かけほど低くならず、古い山脈が長く残る現実の挙動になります。

### 現実味を上げる追加要素

- **岩石の硬さ。** K をセルごとに変えます。古い大陸核は硬く、若い堆積物は柔らかくします。硬い岩の残丘や段差のある川が出ます。
- **氷河侵食。** 氷のあるセルでは、Deal & Prasicek（2021）のような氷河版の stream power 則で削ります。雪線付近で山頂が削り取られ、山の高さが頭打ちになる現象（グレイシャル・バズソー）や、フィヨルド海岸の素地ができます。

### 気候との交互反復

気候 → 侵食（数 Myr 分）→ 気候 → 侵食 → 最終気候、と2〜3往復します。山脈ができると雨陰ができ、雨陰側は削れにくくなり、山の非対称な形が強まる、という連鎖が入ります。

### 調整の目安

K は単位系と格子間隔に依存するので、絶対値ではなく結果で合わせます。最高峰が8〜9 km、主要な造山帯の平均高度が2〜4 km、大河川の流域が大陸の数分の1を占める、といった地球の値が目標です。

## 水文（川・湖）

結論：最終地形と最終気候から「降水−蒸発散」の流出量を求め、窪地を水収支で満たしていきます。これで、海に出る湖、塩湖になる内陸湖、季節だけ流れる川が区別されます。

1. **流出量。** 各セルの年間・月別の流出量を、降水から蒸発散を引いて求めます。蒸発散は気温から可能蒸発散量を出し、Budyko 曲線（乾燥度に応じて降水のうち蒸発する割合を決める経験式）で配分します。
2. **流量の集計。** 侵食段階と同じ流向・並び順で上流から流出量を足し合わせます。1 mm/年の流出が1 km²にあると年1,000 m³なので、流量（m³/s）は「流出（mm/年）×面積（km²）÷約31,600」で換算できます。
3. **湖。** 窪地ごとに、流入量＋湖面への降水と、湖面からの蒸発を比べます。水位を上げて溢れるなら出口から川が続く淡水湖、溢れる前に蒸発と釣り合えば流出口のない塩湖になります。窪地が入れ子になる場合は、Barnes ほか（2021）の Fill–Spill–Merge のように階層の下から順に処理します。
4. **川の表示。** 流量が閾値を超えたセルを川にし、線幅は流量の平方根に比例させます。月別流出が一部の月だけ正なら季節河川（ワジ）として描きます。
5. **湿地とデルタ。** 勾配が小さく流出の多い低地は湿地にします。河口のデルタは侵食段階の堆積がすでに作っています。

確認の目安として、アマゾン川は流域約600万 km²、流出約1,000 mm/年で、上の換算では約20万 m³/s になり、観測値とほぼ一致します。

## 気候区分とバイオーム

結論：気候図にはケッペン区分、地表の見た目（植生）には Whittaker 図のバイオーム分類を使い分け、地形や水文から決まる特殊バイオームを上に重ねます。

| 出力 | 入力 | 手法 |
| --- | --- | --- |
| 気候区分図 | 月別気温・月別降水 | ケッペン＝ガイガー区分。Beck ほか（2018）の定義どおりに判定し、地球の観測図と直接比べられるようにする |
| 植生バイオーム | 年平均気温・年降水量 | Whittaker 図。クラスが少なく、ゲームの地図として読みやすい |
| 植生の密度・資源量 | 年平均気温・年降水量 | Miami モデル（Lieth 1975）で純一次生産量を推定し、森林の濃さや農業適性に使う |
| 特殊バイオーム | 標高・勾配・水文・海面水温 | 下の規則で上書き |

Miami モデルは、気温で決まる値と降水で決まる値のうち小さいほうを純一次生産量（g/m²/年）とします。

```latex
NPP = \min\!\left( \frac{3000}{1 + e^{\,1.315 - 0.119\,T}},\; 3000\,(1 - e^{-0.000664\,P}) \right)
```

### 特殊バイオームの規則

- **高山帯。** 標高による気温低下で森林限界を超えたセル。
- **マングローブ。** 熱帯の海岸で勾配が小さく、河口に近いセル。
- **塩原・砂丘。** 内陸湖の干上がった湖底は塩原、乾燥地で起伏が小さく堆積物が多い場所は砂丘地帯。
- **サンゴ礁。** 水深50 m未満で、海面水温が年間を通して約20℃以上の浅海。
- **海氷。** 月別の海面水温が結氷点を下回る月だけ表示。

境界がくっきりしすぎるのを避けるため、各バイオームの適合度を連続値で計算し、最大値で分類したうえで境界付近を混ぜます。

## 高解像度化と出力

推奨：ゲームで実際に使う地域だけを切り出し、全球の結果を境界条件にして侵食モデルを細かい格子で再実行します。物理的に整合したまま解像度を上げられるのはこの方法だけです。それより細かい質感は、必要なら実在の地形データで補います。

### 3つの方法

| 方法 | 内容 | 長所 | 短所 |
| --- | --- | --- | --- |
| 地域の再シミュレーション | 1,000 km 四方程度を切り出し、全球の隆起速度を補間して入力、境界の川の流入と河口の標高を全球から固定し、100 m〜1 km 格子で stream power を回す | 水系・尾根が全球と矛盾しない | 地域ごとに計算が必要（オフラインなら問題なし） |
| 細分化による増幅 | Peytavie・Cortial ほか（2020）の hyper-amplification のように、標高・水域・地形種別の粗い地図から規則的な細分化で川と地形を足す | 惑星全体を一様に細かくできる | 物理計算ではなく規則ベース |
| 実地形の貼り付け | 実在の数値標高データから、造山の年代や気候が近い場所の断片を探して重ねる（任意機能） | 細部の質感が最もリアル | 継ぎ目の処理が必要。データのライセンス確認が必要 |

地域の再シミュレーションでは、Schott ほか（2023）の「隆起速度を描いて侵食で地形を出す」手法が土台になります。気候も細かい格子で、標高減率と地形性降水モデル（自作の FFT を使う線形理論、D-17）だけ再計算します。

### ゲームへの出力

- **データの基準。** 全データは球面格子のまま保持し、表示用に投影します。
- **投影。** 世界地図は正距円筒図法や面積の歪みが小さい図法、地域図は地域の中心で接するランベルト正積方位図法などを使います。ヘックス盤のゲームなら、球面を六角形（と12個の五角形）で分割するゴールドバーグ多面体が使えます。どれを優先するかは、ゲームエンジンと地図の使い方が決まってから決めます（未決事項）。
- **レイヤー。** 標高（16 bit 以上）、海陸、川（流量つきの折れ線）、湖（淡水/塩湖）、月別気温と降水、ケッペン区分、バイオーム、純一次生産量、プレートと岩石の種類。
- **資源配置への応用。** プレートの履歴はゲームの資源配置にも使えます。たとえば火山弧には銅などの金属鉱床、古い大陸核には鉄や金、堆積盆地には石油や石炭を置くと、地質学的に筋の通った配置になります。

## 検証方法

結論：「見た目がそれらしいか」ではなく、地球で測れる統計と比べて数値で合わせます。地球に近いパラメータで何十個も惑星を生成し、分布として地球が中に入っているかを見ます。

| 指標 | 地球のおおよその値 | 何を確かめるか |
| --- | --- | --- |
| 陸地率 | 約29% | 海水量と大陸地殻量のバランス |
| 高度分布 | 陸の平均約0.8 km、海の平均約3.7 kmの二山型 | 地殻の厚さ・年代から標高への変換 |
| 最高峰・最深部 | 約8.8 km、約11 km | 衝突の厚化と侵食の釣り合い、海溝の深さ |
| 海洋底の年代 | 大部分が2億年未満 | プレートの生成と沈み込みの速度 |
| 主流の長さと流域面積 | 長さは面積の約0.6乗に比例（Hack の法則） | 河川網の形 |
| 乾燥帯の分布 | 陸地の約3割。緯度15〜35°と寒流沿いの西岸に集中 | 気圧帯、海流、湧昇 |
| 雨陰 | 偏西風帯や貿易風帯の山脈で、風下側の降水が大きく減る | 地形性降水 |

### 実施方法

- **気候の単体テスト。** 地球の実地形を入力し、観測の気温・降水・ケッペン区分図との一致率を出します。
- **地形の単体テスト。** 地球の主要な造山帯の隆起速度を与えて侵食だけを回し、山脈の幅と高さ、河川網の形を実地形と比べます。
- **目視の比較テスト。** 実在の地域図と生成した地域図を同じ配色・図法で並べ、どちらが本物か当ててもらいます。見分けられなくなることが最終目標です。
- **回帰テスト。** 固定シードの惑星を数個用意し、変更のたびに上の指標を自動計算して記録します。

| M5 水文とバイオーム | 流出、湖、川、ケッペン区分、バイオーム、検証レポート | 最初の完成惑星を出力でき、地球入力のケッペン区分図が観測とおおむね一致する |
| M6 プレートの時間発展 | 沈み込み、海嶺、衝突、分裂、ホットスポット | 海洋底の年代勾配、新旧の造山帯、受動的縁辺が現れる |
| M7 連成と追加要素 | 気候と侵食の往復、堆積、アイソスタシー反発、岩石の硬さ、氷河侵食、較正 | 検証指標が地球の範囲に入る |
| M8 高解像度化と出力 | 地域の再シミュレーション、投影とゲーム向け出力 | 100 m〜1 km の地域地形が全球と整合する |

### 計算コストの目安

約65万セルの場合、侵食は1ステップが0.1秒前後なので、3,000ステップで数分です。プレート（250ステップ程度）と気候（数年分の月別ループ）も数分〜十数分なので、1惑星あたり合計で数十分程度と見込めます（実装次第の概算）。

### 技術スタック

- **基準実装。** Rust の f64。並列化は分割と集計の順序を固定して行います。
- **主な依存。** 数学関数に libm、幾何述語に robust（どちらも純 Rust でバージョン固定）。入出力に serde・serde_json・png、CLI に clap、設定ファイルに toml を使います。一覧は D-10 にあります。
- **開発環境。** mise で Rust ツールチェーン（ブラウザ版ビューア用の wasm32 ターゲットを含む）、cargo-deny、wasm-bindgen-cli のバージョンを固定します（D-23）。開発用の Python（`tools/` のみ）も最初のスクリプトを書くときに mise で固定します。
- **自作するもの。** 乱数生成器、球面ドロネー分割、FFT、`.kfield` 形式と `.kgrid` 形式（格子）。
- **ビューア。** wgpu でネイティブとブラウザ（WebAssembly。WebGPU、なければ WebGL2）の両方に対応します。ブラウザ版は利用者が選んだ世界ディレクトリをブラウザ内で読み、サーバー側の処理はしません。
- **GPU 経路（将来）。** wgpu の f32 で、侵食や地域の高解像度化など重い段階から移します。
- **参考実装。** stream power と流路計算は fastscapelib（C++）が読み物として有用です。コードを移植する場合は元のライセンスを確認します。
